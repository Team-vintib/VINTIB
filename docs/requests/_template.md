# <요청 제목 — 무엇을 해 달라는지 한 줄>

- 요청: <요청쪽> → <받는쪽>
- 날짜: YYYY-MM-DD
- 기한: YYYY-MM-DD (없으면 "없음")
- 상태: 요청
- 관련: <계획 항목(T2-1 등) · 커밋 · 문서 경로>

## 배경

왜 필요한지 2~4문장. 지금 코드·문서가 어떻게 돼 있고 무엇이 문제인지. 근거는 경로(필요하면 커밋 해시)로 적는다.

## 요청 내용

받는 쪽이 하나씩 답할 수 있게 항목으로 나눈다. 선택지가 있으면 요청쪽의 추천을 먼저 쓴다.

- [ ] 1. …
- [ ] 2. …

## 응답

받는 쪽이 채운다. 채우면 머리의 상태를 `답변`으로, 색인 표도 같이 고친다.

- 응답: <받는쪽>, YYYY-MM-DD
- 결정: 수락 | 수정 수락 | 보류 | 거절
- 내용: 항목별 답. 요청과 다르게 정했으면 이유.

## 반영

결정대로 바꾼 뒤 채운다. 상태를 `반영`으로.

- 커밋·PR: <해시 또는 링크>
- 확인: 무엇으로 확인했는지(테스트·측정·화면)
