## 노션 원본과 다른 점

- 노션 페이지 속성(ID, 문서유형, 최종 편집 일시·편집자, 작성자, 생성 일시)과 "관리 정보" 절, 템플릿 안내 문구는 옮기지 않았다. 원본 기준일은 위 표에 적는다.
- **이 레포에는 채팅 AI 기능이 없다**(2026-10-29 사용자 결정). 원본의 LIVE-007(AI용 음성 텍스트 변환), CHAT-002·003(반복 질문 자동 답변·근거 없는 답변 제한), CHAT-004(비매너 채팅 관리), "반복 질문 AI 흐름" 절, 해당 MVP 항목, 요구사항 명세서의 관련 표현, 유스케이스 다이어그램의 "라이브 음성 텍스트 변환"·"반복 질문 AI 자동 답변"을 뺐다. 기능 ID는 다시 매기지 않았다.

## 사본을 가져오거나 갱신할 때

1. 노션에서 **Markdown으로 내보낸** 파일을 쓴다. 공개 페이지를 긁어 오면 표가 깨진다.
2. 파일 맨 위에 제목 한 줄을 두고, 본문은 그대로 옮긴다. 노션 전용 태그가 남아도 지우지 않는다.
3. 이 표의 "사본 기준일"과 "원본 상태"를 갱신한다. 이전 사본과 달라진 점이 진행 중인 작업에 영향을 주면 관련 파트에 요청 문서로 알린다.
4. 사본 갱신은 사용자 승인 후 한다.
