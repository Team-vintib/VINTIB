# FE — Claude 작업 규율

담당 범위·기술 스택·실행 방법은 `README.md`, FE 코드 컨벤션과 자료 우선순위는 `AGENTS.md`(이 폴더)를 따른다. 이 문서에는 에이전트가 지켜야 할 규율만 적는다.
루트 `CLAUDE.md`의 공통 규칙(범위, 커밋 규칙, push 금지 등)은 이 폴더 작업에도 그대로 적용된다.

## 새 기능 계획

신규 화면/기능 등 새 기능은 바로 구현하지 않는다. 먼저 계획을 세워 `docs/plans/FE/`(루트 기준)에 md로 기록하고, 사용자 승인 후 그 계획대로 구현한다. 형식은 루트 `docs/plans/README.md` 참고. 버그 수정 등에는 적용하지 않는다.

## 다른 파트 코드 수정 금지

BE/AI 코드는 직접 수정하지 않는다. BE나 AI 쪽 변경이 필요하면 `docs/requests/`(루트 기준)에 요청 문서를 남긴다. 파일 이름·상태·형식은 루트 `docs/requests/README.md` 참고. 처리한 요청 문서는 지우지 않고 상태만 바꾼다.
